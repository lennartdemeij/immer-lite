# Immer Lite Vocabulary

- **Publication**: one locally opened EPUB or PDF, identified by its immutable fingerprint.
- **Section**: an ordered semantic division of a publication, such as a chapter or introduction.
- **Block**: an ordered semantic unit in a section: text, image, or scene break.
- **Sentence**: the canonical sentence range within a text block.
- **Portion**: one viewport-aware reader unit produced from canonical blocks.
- **Reader anchor**: a stable location in a publication, based on section, block, sentence, and line fallback data.
- **Annotation selection**: one unsaved, contiguous text range inside a canonical block.
- **Text annotation**: a persisted note attached to an annotation selection and publication fingerprint.
- **Continuation boundary**: the visual boundary between portions that split one text block.
